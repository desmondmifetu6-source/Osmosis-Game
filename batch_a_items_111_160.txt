142. [antiderivative]
The antiderivative of a function ƒ ( x ) is a function F ( x ) whose derivative equals ƒ ( x ). The process of solving antiderivatives is called antidifferentiation or indefinite integration and its opposite operation is called differentiation , which is the process of finding a derivative. For example, the function F ( x ) = x 5 /5 is an antiderivative of f ( x ) = x 4 . Since the derivative of a constant is zero, x 4 has an infinite number of antiderivatives such as ( x 5 /5) - 10, ( x 5 /5) + 2, etc. Thus, all the antiderivatives of x 4 can be obtained by changing the value of C in F ( x ) = ( x 5 /5) + C ; where C is an arbitrary constant known as the constant of integration. Basically, the graphs of antiderivatives of a given function are vertical translations of each other, with each graph's location depending on the value of C . Antiderivatives are related to definite integrals through the fundamental theorem of calculus and they are important because they can be used to compute definite integrals.
