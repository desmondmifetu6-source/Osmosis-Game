86. [algebraic function]
A function that may be expressed in a finite number of terms, of only the elementary algebraic operations of addition, subtraction, multiplication, division and root extraction, for example, f ( x ) = nx 3 + x 4 - 2 x . Another way of saying this is that the function f ( x ) is algebraic if y = f ( x ) is a solution of an equation of the form p n ( x ) y n + ... + p 1 ( x ) + p 0 ( x ) = 0, where p 0 ( x ), p 1 ( x ), ..., p n ( x ) are polynomials in x . All polynomials are algebraic. A function that satisfies no such equation is transcendental. There are various types of algebraic functions. A rational function does not have any fractional powers of the variable or variables. Integral functions do not include the operation of division in any of their terms. A homogeneous function is one in which the terms are all of the same degree, i.e., the sum of the indices of the variables in each term is the same for every term.
